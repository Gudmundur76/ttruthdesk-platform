## How to use in a new session

```bash
# 1. Install the binary (one-time per machine)
curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh \
  -o /tmp/cbm-install.sh && bash /tmp/cbm-install.sh --skip-config
export PATH="$HOME/.local/bin:$PATH"

# 2. Restore the graph from the committed snapshot
mkdir -p ~/.cache/codebase-memory-mcp
gunzip -c .codebase-memory/graph.db.gz > \
  ~/.cache/codebase-memory-mcp/home-ubuntu-ttruthdesk-platform.db

# 3. Verify it's queryable
codebase-memory-mcp cli index_status '{"project":"home-ubuntu-ttruthdesk-platform"}'

# 4. Query examples
# Architecture overview
codebase-memory-mcp cli get_architecture '{"project":"home-ubuntu-ttruthdesk-platform","aspects":["all"]}'

# Find all HTTP routes
codebase-memory-mcp cli search_graph '{"project":"home-ubuntu-ttruthdesk-platform","label":"Route"}'

# Trace call chain from verifyClaimRoute
codebase-memory-mcp cli trace_path '{"project":"home-ubuntu-ttruthdesk-platform","name":"verifyClaimRoute","direction":"outbound","depth":4}'

# Semantic search
codebase-memory-mcp cli search_graph '{"project":"home-ubuntu-ttruthdesk-platform","semantic_query":["pubmed","evidence","citation"]}'
```

## Automatic updates

The `.github/workflows/codebase-memory.yml` workflow re-indexes and commits an updated
snapshot on every push to `main`. No manual action required.

## Project name

The project is registered as `home-ubuntu-ttruthdesk-platform` in the local cache.
This matches the path-based naming convention used by codebase-memory-mcp.
